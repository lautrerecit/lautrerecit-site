L'indigénat — fabriquer le sous-citoyen

À partir de 1881, un régime juridique d'exception range les Algériens musulmans dans une catégorie à part : sujets français sans être citoyens, soumis à des délits qui n'existent pour personne d'autre.

Ce module montre l'opération centrale du système : la loi fabrique un statut inférieur, codifié et permanent. Le sous-citoyen est un produit administratif.

Ce que vous saurez après ce module

  • Le Code de l'indigénat et ses délits spéciaux
  • Sujet sans être citoyen : l'inégalité inscrite dans le droit
  • Comment l'administration fabrique un statut inférieur

Le rappel.

Cinq à six choix. Aucun ne teste votre mémoire : chacun oppose des lectures défendables, et une seule tient. Le vrai enseignement est dans la correction de celle que vous aurez choisie.
